# CodeAlpha FAQ Chatbot

## Project Overview

This project is an AI-based FAQ Chatbot developed as part of the CodeAlpha Internship.

The chatbot uses Natural Language Processing (NLP) techniques to understand user questions and provide the most relevant answers from a predefined FAQ dataset.

## Technologies Used

- Python
- Tkinter
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- JSON

## Features

- Simple graphical user interface
- Accepts user questions
- Finds the most relevant FAQ
- Uses TF-IDF and Cosine Similarity
- Provides instant answers

## Project Files

- `chatbot.py` – Main chatbot program
- `faqs.json` – Frequently asked questions and answers
- `requirements.txt` – Required Python libraries
